## 今天交付了什么

项目从需求文档和视觉概念进入了真正可运行的全栈开发。用户可以注册、登录、保存个人资料，在游戏、学习、竞赛、户外四区查看数据库内容，发布讨论、查看详情、搜索，并编辑或删除自己的讨论。两个独立浏览器账号可以读取同一条帖子；数据库与服务端重启后，已保存的帖子和登录会话仍然保留。

界面采用用户暂定的新粗野主义方向，保留拖动回弹、按压反馈、详情滑动返回和列表滚动恢复。当前是响应式网站平台，浏览器即可使用。

首周账号与基本讨论的技术核心已通过本机验收。竞赛招募、岗位与审核、队伍群聊、AI 和管理模块仍未实现；今天的交付不能称为完整参赛作品。

## 2. 工程与真实数据库

### 今天建立的结构

| 位置 | 责任 | 实际完成 |
| --- | --- | --- |
| `apps/web` | 用户界面 | React、TypeScript、Vite、路由、查询状态、表单、Motion 交互 |
| `apps/server` | API 与权限 | Express、会话、CSRF、账号资料、主题、讨论 |
| `packages/contracts` | 共享数据契约 | Zod 输入校验、公开与私有 DTO、四区信息 |
| `prisma` | 数据结构与演进 | School / User / Profile / Session / Topic / Post、首次 SQL 迁移、显式演示 seed |
| `scripts` | 可重复运行 | 环境初始化、数据库、开发启动、构建、测试与重启探针 |
| `docs` | 设计与证据 | 规格、决策、架构、API、验收、周记录、AI 摘要 |

实际链路是浏览器 → HTTP API → Prisma → PostgreSQL；持久化数据没有用静态数组或 localStorage 代替。

### 环境与依赖选择

- 本机 Node.js 24.16.0、pnpm 11.5.1；依赖版本写入各 package.json 和 `pnpm-lock.yaml`。
- React 19.3.1、Vite 8.3.4、Express 5.3.0、TypeScript 7.0.2。
- PostgreSQL 18.4；Prisma、客户端与 pg 适配器统一 7.10.0，未采用查询到的 Prisma 8 RC。
- 本机没有 Docker 或现成 PostgreSQL，采用固定版本的 embedded-postgres 开发组件启动真正的 PostgreSQL。组件包带 beta 标记，仅用于本地；保留外部 PostgreSQL / Compose 方案。
- 前端开发端口 5173、API 3001、数据库 5432，均使用回环地址。

详细架构：[ARCHITECTURE.md](../ARCHITECTURE.md)。依赖与来源：[THIRD_PARTY.md](../THIRD_PARTY.md)。

## 3. 账号、资料与安全边界

| 用户行为 / 风险 | 今天实现的处理 |
| --- | --- |
| 注册、正确 / 错误密码登录、注销 | 真实 API 与数据库记录，错误受控返回，注销使服务端会话失效 |
| 刷新后保持登录 | 随机不透明 Cookie 对应数据库会话，数据库仅保存令牌摘要 |
| 密码保存 | Argon2id 摘要，不保存明文密码 |
| 跨站写入与伪造请求 | HttpOnly、SameSite Cookie；写入检查 Origin 与 CSRF；生产 Cookie 使用 Secure |
| 会话刷新后的 CSRF | 从服务端密钥与当前会话令牌稳定派生；注册 / 登录旋转会话 |
| 修改本人资料 | 输入校验，公开资料与本人私有 DTO 分离 |
| 公开读取其他用户 | 不返回邮箱、密码摘要、会话令牌等私有字段 |
| 学校与技能展示 | 明确是自述，邮箱未核验，演示学校为虚构 |

实际位置：`apps/server/src/auth.ts`、`password.ts`、`dto.ts`、`apps/web/src/lib/auth.tsx`、`pages/Auth.tsx`、`pages/Profile.tsx`。

当前限流是单实例内存方案，不宣称已经具备分布式生产限流。没有接入真实学校认证或邮件服务。

## 4. 四区与基础讨论闭环

1. 四区、学校与主题来自 API 和 PostgreSQL。演示 seed 提供两所明确标记为虚构的学校、12 个主题和演示帖子。
2. 支持学校、分区、主题和关键词过滤。没有结果时显示空态，请求失败可重试。
3. 用户登录后发布帖子，正文以普通文本渲染。
4. 列表与详情读取同一数据库记录；分页按创建时间和 UUID 形成稳定游标。
5. 作者可以编辑或软删除；匿名写入被拒绝，非作者修改被拒绝。
6. 编辑带 revision 校验，避免旧表单覆盖新版本；失败保留输入，供重试或调整。

实际位置：`apps/server/src/posts.ts`、`apps/web/src/pages/Discover.tsx`、`Publish.tsx`、`PostDetail.tsx` 和共享契约。

未实现图片、评论、点赞和收藏；不能把“基础讨论已通过”扩写成完整社区模块全部完成。
