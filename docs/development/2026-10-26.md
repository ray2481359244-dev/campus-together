## 本轮交付

- “我的 → 我的队伍”分页显示当前有效队伍；招募详情也可进入。私有队内名单仅当前有效成员可见，展示必要的自述学校 / 技能、角色、岗位与加入时间，不含邮箱或申请说明。
- 普通成员主动退出；队长填写原因移除普通成员。名额与岗位占用释放，队内读取撤权。队长不能通过普通退出或移除留下无负责人队伍。
- 关闭招募有独立时间标记，保留现有队伍 / 成员；未处理申请写为 EXPIRED、更新版本和处理时间，保存本人关闭通知。关闭后不再申请 / 批准，成员退出也不重新开放。
- 通知扩展为审核、退出、移除、关闭待审结果。互斥来源 CHECK、复合外键与唯一键保护归属，历史审核通知原样保留，通知是当时结果，当前身份以详情为准。

采用规格默认建议：首版退出或被移除后不能重新加入同一队伍。为区分该规则，新条件快照使用 v2，旧 v1 仍可读。成员新增 revision 和不可变 MembershipChange；关闭记录 RecruitmentClosure 唯一。按排序 User → Recruitment → Team 写锁协调，状态、名额、通知和事件同事务。相同原操作可重试，相反操作、不同原因或后续版本不能被旧请求覆盖；原申请 / 批准重试不恢复失效成员。

退出 / 移除后服务端新私有读取立即拒绝。页面重新可见或手动刷新后收起原名单；没有 Socket 实时撤权。未知结果保留原版本与原因，离开成功清除队内缓存并返回我的队伍。
