# 本地参赛演示操作说明

2026-10-29：本轮按“先准备本地演示，再做异机复现、真实试用和参赛材料”的顺序推进。这个入口运行构建版应用与真实 PostgreSQL，只有本机可访问，不是公网或局域网发布。AI 保持规则模式；没有配置或调用真实模型。

## 启动和停止

首次使用需要安装 Node.js 24、pnpm 11.5.1，再在仓库根目录执行：

```powershell
pnpm.cmd install --frozen-lockfile
pnpm.cmd demo
```

依赖已安装后，可以双击仓库根目录的 **启动参赛演示.cmd**，或继续使用 `pnpm.cmd demo`。出现“参赛本地演示已就绪”后，打开 http://127.0.0.1:3180/discover 。保持终端运行，Ctrl+C 停止本次网页 / API，数据库和数据保留；再运行同一命令即可继续。

启动器自动保留 / 生成本地 `.env`、准备独立 `campus_demo` 库、生成客户端、应用迁移、导入虚构基础数据、构建前后端，并从同一个 3180 端口提供网页和 API。它不下载或升级依赖，不需要运行 Vite 开发服务器。PostgreSQL 未启动时可启动本项目的本地组件；已存在的数据库服务不会随演示退出停止。

已经运行时再次执行只提示地址，不启动第二份；端口被其他程序占用时拒绝，不结束未知程序。只读查看演示状态：

```powershell
pnpm.cmd demo:status
```

原来的 `pnpm local` / 启动平台.cmd 仍是开发入口，使用原有主库及 5173 / 3001。请使用不同浏览器资料或独立隐私窗口分别访问两套环境：同一浏览器对 127.0.0.1 不同端口会共享 Cookie，交替使用可能需要重新登录。不要把 127.0.0.1 与 localhost 混用。

## 一次完整产品演示

1. 在发现页浏览四区的虚构讨论。以小河登录，从招募大厅选择竞赛，打开标题带“校园协作参赛作品 · 演示”的当前场景；画面说明它是虚构的产品演练。
2. 切换小林，选择同一招募的“前端开发”，确认所列协作时间，点击“核对申请条件”，查看依据后提交。解释待审不占名额。
3. 小河刷新本队申请，查看条件和说明，批准入队。小林刷新申请查看结果，并从“进入我的队伍”进入群聊。观察真实人数由 1 / 3 变为 2 / 3。
4. 双方发送文字、设置公告。用小梅访问同一队伍链接，展示非成员不可读；管理员也不拥有任意浏览队内聊天的权限。
5. 小河进入队伍详情，填写说明并确认开始，再确认结束。小林刷新群聊看到只读归档，原消息保留，不能继续发言。结束不可重开。
6. 作为补充，打开学习招募，以小林核对条件并直接加入，说明它与竞赛审核加入的区别。游戏 / 户外展示各自的场景字段即可。
7. 管理功能可单独演示：普通用户举报一条公开讨论，管理员填写原因处理，再查看审计及结果。不要为演示而生成真实个人资料或违规内容。

上述是产品操作脚本，不是已制作的视频。录制时再按赛事要求分配时间，给真实 AI 协同开发过程留出独立片段；应用内的规则辅助不能代替 AI 开发过程证据。

## 开始新一轮，不清空旧记录

每轮有四区各一条招募，标题带同一个六位演示编号。首次生成时协作开始在八天后、招募截止在七天后；这些是虚构演练时间，参与者仍须显式确认。重启不会自动延长截止或重开已结束的队伍。

需要重新录制、活动已结束 / 到期，或想从头体验时，在同一仓库的另一个终端执行：

```powershell
pnpm.cmd demo:scene
```

服务运行时会增加一组新招募，然后命令结束；服务未运行时会先启动演示并保持该终端运行。新编号及四条链接会在终端输出，旧申请、消息、审核和活动状态保留。当前场景回执在忽略上传的 `.local/demo/<实例编号>/ready.json`，包含虚构招募 ID；当前轮次和原请求意图同目录保存，用于中断后按原键核对。不要删除这些文件来重置演示。

## 数据与故障边界

`campus_demo` 与原 `campus` / `campus_test` 是不同数据库，角色凭据来自本地配置但不显示。数据库附有本检出目录的归属标记；同名库若无标记或属于其他目录，启动拒绝，不能自动接管。生产模式、远程数据库及用原库充当演示库同样拒绝。没有添加公开管理员初始化接口。

遇到同名库已存在 / 端口占用，不删除旧库，可以在准备另一套独立演示时显式换名字和端口：

```powershell
$env:DEMO_DATABASE_NAME='campus_demo_second'
$env:DEMO_PORT='3181'
pnpm.cmd demo
```

后续状态 / 新场景命令必须使用同一终端环境变量。换回默认值可关闭该终端后新开一个；不会自动搬迁已有数据。名称只接受 `campus_demo` 或以它开头的下划线小写字母 / 数字后缀。

数据库角色需有创建独立数据库和迁移权限。使用自行管理的本地 PostgreSQL 而权限不足时，请数据库负责人创建专用环境，不要改用主库或直接给正式应用角色增加超级权限。

本地组件的数据位置沿用 `.local/runtime.json` 中记录的持久化目录；电脑关机后其他人无法访问。演示版不是数据备份，备份 / 恢复边界见 [部署交接](../DEPLOYMENT.md)。不要将这套公开演示密码的实例用内网穿透直接开放到互联网。
