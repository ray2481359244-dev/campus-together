# Campus Neo-Brutal / UI 设计语言 v1.2

日期：2026-10-15。用户暂定新粗野主义概念为开发核心模板，取代 v1.1 清新版的视觉基线。原型已归档在 design/campus-brutal-concept.html，实际应用必须连接真实 API。

## 视觉

奶油白 #FFF9EF、文字与边框 #20201E、酸黄强调 #F5FF62。竞赛紫 #C3B3FF、学习青 #A7DFED、游戏黄 #F5FF62、户外绿 #B7EDAA；创作入口可用粉 #FFB3CF。

以 2—3px 实线边框、3—6px 无模糊偏移阴影、4—6px 小圆角建立识别。大标题 36—64px / 900，分区标题 22—28px / 800，正文和输入 16px，辅助内容至少 12px。英文编号只作辅助，关键操作必须有中文文字。

首页是海报式大标题、可拖拽兴趣标签、规整分区网格与真实讨论。招募和讨论保持清晰列表，不把所有页面都做成装饰拼贴。桌面采用侧栏与宽内容布局，不放大成居中的手机壳。

## 交互模板

- 兴趣标签直接跟随拖拽，松手弹簧复位；点击可进入相应区。拖动不触发意外点击，不影响其他按钮。
- 按钮通过偏移与硬阴影收缩表现按压，及时响应，约 150—220ms。
- 详情进入约 260—320ms；移动端左边缘右滑跟随指针，距离不足或取消回弹，完成后返回原列表。
- 区域切换支持点击和键盘，选中指示条平滑吸附。新动作打断旧动画，不排队回放。
- 遵循 prefers-reduced-motion；关闭额外动画后，直接拖动和业务功能仍能使用。
- 导航与表单均可键盘操作，焦点可见，触控目标至少约 44px。表单有标签，错误保留输入。

## 真实状态

加载、空数据、错误重试、未登录、无权限、提交中和成功有明确表现。演示环境持续标识。竞赛招募草稿与发布已接入，申请 / 入队 / 聊天尚未实现并明确说明，不产生模拟申请或聊天记录。资料自述、邮箱未验证与规则模式如实标注。

390px / 1440px 作为主要验收视口，320px 不横向溢出；较窄屏幕减少留白并允许换行，不能缩小正文来勉强塞入。真实验证结果记录在 docs/PROGRESS.md。

## 2026-10-17 实施校准

沿用 v1.2 视觉，不替换模板。主要业务辅助文字落实 12px，手机筛选 / 搜索输入为 16px，主触控控件至少约 44px；品牌标识中的装饰小字不承担业务说明。

键盘可跳到主内容，四区支持方向键 / Home / End；讨论详情焦点到标题，Esc 返回且恢复原卡片焦点与滚动。搜索清除后焦点留在输入，前进 / 后退同步 URL 条件。以真实长内容检查四档视口，详情截图在入场结束后保存；不将中间动画帧作为最终视觉。

CSS 已考虑底部安全区，真机软键盘与原生 200% 缩放仍需单独实测。完整无障碍认证不从本轮局部检查推导。

## 2026-10-30：已确认的想法云与内容分层

沿用黑黄品牌和纸色，新增原创 Q 版同学与柔彩想法云。内容按“原始想法 / 回应 / 行动 / 证据”采用白纸、浅紫、浅绿、浅蓝的不同容器与边角。UNKNOWN 条件为浅黄；审核结果使用中性色，不能用成功色包装未知或拒绝。动态用户标题用完整正文字体，受控装饰文案才用子集手写字体。

按钮轻压回弹、真实工作区 FLIP、短路由入场和细小指针跟随共享动效偏好；动画不延迟业务操作。页面清单、具体时长和验证边界见[全站交互复核](INTERACTION_REVIEW_2026-10-30.md)。
