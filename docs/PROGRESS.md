## 实际修复

- 列表展开详情的独立层缺少路由参数，导致请求 /posts/undefined；现在详情层由明确的 posts/:id 路由渲染。
- 表单字段说明混入标签名称影响明确定位；将标题、正文和技能的说明移到 aria-describedby。
- 技能输入按字符立即拆分会吞掉末尾逗号；现在保留输入文本，再生成受校验标签数组。
- 滑动返回的外层实色遮住底层页面；现在只有移动面板不透明，返回时可见原页面，返回后恢复列表滚动位置。
- 测试网络拦截提前解除导致 Route already handled；等待实际请求完成再回收。
- Windows 测试进程清理需正常本地进程权限，已验证测试结束后回收专用服务。
- 路由拆分移除单个 600kB 构建块警告；服务端显式打包共享契约并声明其 zod 运行依赖。
