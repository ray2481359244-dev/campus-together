- 修复注册与会话分属不同事务的问题：账号 / 资料 / 会话创建及旧上下文撤销同事务，提交后才设置 Cookie；会话写入失败不遗留账号，旧上下文仍可重试。
- 登录轮换和注销按条件争用旧会话，避免同一旧上下文被多个成功请求重复替换；被拒绝请求不覆盖 Cookie。
- 浏览器的账号相关请求携带 X-Session-User，服务端按实际 Cookie 会话核对；另一个普通标签页切换账号时，旧表单不自动改为新账号写入。同身份 CSRF 更新可重试；身份变化必须重新确认。
- BroadcastChannel 仅传递状态变化，不传令牌 / 资料；收信标签页清理查询缓存和当前表单后显示恢复页。不支持该通知方式时，下一次账号相关请求仍由服务端拒绝身份不一致。
- 客户端按会话版本丢弃旧请求结果，迟到的失败不干扰退出后的页面，迟到的成功也不恢复旧用户。资料普通保存失败仍保留输入；登录状态读取失败明确显示重试，不能冒称已注销。
