## 体验任务

1. 保持启动窗口运行，打开本机平台并注册账号。学校和技能是自述，演示学校为虚构。
2. 修改昵称、简介和技能，保存后刷新，检查是否保留。
3. 点击四个兴趣入口和讨论板内的四个筛选；快速连续切换，观察标识、滚动和加载状态。
4. 在一个主题发布讨论，另开隐身窗口用第二个账号读取。
5. 作者编辑，另一账号刷新查看；确认其他账号没有编辑入口。
6. 搜索没有结果的关键词，再清除搜索；切换到没有内容的学校。
7. 注销并刷新，检查需要登录的页面是否有清楚引导。

每个任务记成功 / 有困难 / 失败，并记录具体步骤、页面、设备和预期。当前只在本机或自行启动源码后体验；没有公网演示站。

## 需求初访提纲

建议首轮约 2—3 位同学，不把建议人数写成实际人数。每次约 10—15 分钟，可从以下真实经历问起：

- 最近一次找学习、竞赛或活动伙伴是什么时候？最后怎样找到人？
- 当时最费时间或最不确定的环节是什么？请举具体例子。
- 对方需要告诉你哪些信息，你才愿意申请或联系？
- 时间、岗位、技能和学校分别怎样影响选择？
- 看完目前的页面，是否知道下一步该点哪里？哪里让你误解？

记录匿名编号、日期和实际场景即可，不收集不必要的私人资料。是否同意截图 / 录音需由实际参与者决定。
