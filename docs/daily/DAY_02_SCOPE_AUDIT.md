## 本轮可验收交付

1. 作者可保存、继续编辑和删除竞赛招募草稿；其他人无法看到私有草稿。
2. 发布前补齐主题、标题说明、线上 / 线下地点、开始结束与截止、比赛与项目方向、投入 / 协作说明、人数和岗位，并预览确认。

4. 发布在同一数据库事务中创建队伍、岗位、队长成员关系、聊天空间元数据和事件；并发重复发布不重复建队，失败整体回滚。
