# W1-05 讨论验收与体验步骤

实际复核日：2026-10-18，原计划日为 10 月 19 日。应用节点 `0fba6d0`。这是首周文字讨论范围，完整社区并未全部完成。

## 当前可用

四区讨论按学校 / 主题 / 关键词浏览，稳定游标分页；真实注册后发布文字讨论，作者可修改与软删除，他人只能读取。作者与学校由会话和资料确定，不能由客户端伪造。原有匿名、CSRF、越权、主题停用及公开字段过滤检查继续通过。

这次补齐编辑内容保护：表单基准与 revision 固定，后台读取不覆盖输入；冲突需要先核对、再明确确认载入服务器版本。保存失败和原文删除都保留本页输入供手动复制。

## 怎样体验双标签页编辑

1. 在 [本地平台](http://127.0.0.1:5173/discover)登录自己的账号，创建一条测试讨论，进入“编辑讨论”。
2. 同一个浏览器开另一标签页，使用相同账号编辑同一讨论。两页分别写不同标题，在第二页先保存。
3. 回到第一页，点击“核对已保存版本”。服务器版本会单独展示；下方尚未保存的输入不应变动。页面重新获得焦点后的后台读取同样不应覆盖输入。
4. 第一页仍基于旧版保存时应提示冲突，不能覆盖第二页已保存内容。保存按钮会停止重复冲突提交。
5. 如需改用新版，点击“用此版本重新编辑”。可以选择“继续保留我的输入”；只有“确认载入已保存版本”才替换下方内容并更新编辑基准。合并所需文字请先手动复制，系统没有自动合并。
6. 原讨论在另一页删除后，再核对应提示不存在，但本地未保存的正文仍在。首次打开已删除链接则正常显示不可见错误。

普通保存失败保留当前内容，可检查网络后重试。若编辑请求可能已经提交但响应丢失，应核对服务器版本；不能据错误判断原请求未生效。新建讨论尚无请求幂等，遇网络中断先回列表核对，不建议直接反复发布。

账号在另一标签页注销 / 切换时仍适用既有身份恢复规则，会清除旧账号缓存与未提交表单，防止内容转移到新账号；不与同账号普通读取失败混为一谈。关闭或刷新整页没有自动备份保证。
