## 现在可以体验

1. 打开平台后按 Tab，首先出现「跳到主要内容」，按 Enter 可直接进入内容区域。
2. 聚焦讨论板四区按钮后，用左右方向键切换，用 Home / End 到首尾区域；指示器平滑横移，内容仍从真实 API 获取。
3. 用 Enter 打开讨论卡片，焦点进入详情标题。Esc 返回后，焦点和滚动位置回到原卡片；触摸拖拽、取消和边缘返回继续可用。
4. 作者打开删除确认后先按 Esc，只取消确认并回到删除按钮，不删除帖子；再次 Esc 才返回。
5. 提交讨论搜索，再前进 / 后退，输入框与实际条件一致。「清除讨论搜索」会回到输入框，保留当前区域 / 主题。
6. 手机辅助说明和主控件更清楚：主要辅助文字至少 12px，筛选 / 搜索输入 16px，主要触控控件至少约 44px；颜色、硬边框与跟手交互保持既有模板。

## 修复中发现的回归

首轮对照有 3 项预期失败：没有跳转主内容、搜索后退时输入保持旧值、手机辅助文字为 11px，低于既定基线。实现后首轮完整检查为 17 / 18，通过；手机切区发生 30px 额外滚动。定位到统一给按钮增加的 scroll-margin，改为仅给表单输入留出滚动空间，原「切区滚动变化小于 2px」断言保持不变，最终通过。

后续截图检查发现详情尚在入场淡入阶段，修正测试捕捉时机后完整 19 项再通过。这是证据捕捉问题，不宣称页面最终颜色本来灰暗或移除了动画。
