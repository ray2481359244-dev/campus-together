# 兴趣区切换实际验证

## 修复前

用 Edge 移动视口 390px 访问真实平台，延迟学习区帖子请求后点击入口。

| 观察 | 结果 |
| --- | --- |
| 文档导航次数 | 1，没有真正整页刷新 |
| 旧卡片是否仍在 | false，列表被加载框替换 |
| 选中标识是否仍是原 DOM | false，标识被重新创建 |

原始探针结果位于忽略的 `.local/d2-before-switch.json`，截图为 `.local/screenshots/d2-before-switch.png`。

## 修复后

另用与修复前相同的首页兴趣入口操作复查：旧卡片保留 true、标识仍为原 DOM true、文档导航次数 1、标识竖直位移 0、旧结果 inert true。探针结果在 `.local/d2-after-switch.json`。这是对用户所述首页入口的直接复验，不只测试讨论板按钮。

`pnpm test:e2e` 共 5 / 5，通过。新增两个视口用例验证：

1. 学习请求被暂停时，原列表仍显示，带更新提示并 inert，原加载图标不出现。
2. 标识仍为同一个 DOM，位移只有 X 轴，稳定后与目标按钮左边界相差小于 1px。
3. 讨论板内切换期间滚动位置变化小于 2px，文档没有重新导航。
4. 暂停的学习请求未完成时切换游戏，最终保持游戏内容，不被旧响应覆盖。
5. 减少动态效果模式下切换户外正确，页面无横向溢出。

手机与桌面截图：`.local/screenshots/d2-switch-pending-390.png`、`1440.png`，均已实际检查。截图和工具日志不在公开 Git 中，测试源码和结果说明可核对。

这些检查证明所列行为，不能证明所有设备均有固定帧率。负责人对主观顺滑程度的复验仍待实际进行。
