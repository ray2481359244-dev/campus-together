## 后续每条链怎样归档

每个核心功能目录使用 `docs/ai/chains/AI-YYYYMMDD-编号/`，至少包括：

1. `README.md`：目标、必要上下文、开始 / 完成提交、涉及文件、验证步骤。
2. `conversation.md` 或实际工具导出的文件：按顺序保留真实 Prompt、AI 建议、人的反馈与后续修改；明确来源和截断。
3. `verification.md`：实际命令、结果、缺陷与修复；大文件截图 / 录屏放参赛附件并登记文件名和校验值。

不能事后让 AI 扮演选手补写修复提示。没有真实反馈的地方写“AI 自检”或“未发生”。模型版本只有工具明确提供时才记录，不根据产品名称猜测。

保留敏感信息原件时只留在受控本地；公开版删除真实令牌、密码、个人资料，并记录脱敏范围。演示用虚构账号与 `.env.example` 的占位值要与真实凭据区分。
