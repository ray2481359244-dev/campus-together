## 动效约定

- 所有原生按钮、链接、summary、role=button、复选框与单选框由一个委托层处理。轻压 80ms，释放后回弹落位 360ms；使用独立 CSS scale，保留拖动和路由 transform。键盘激活也有反馈。
- 点赞 / 收藏继续在服务端确认成功后显示业务成功反馈。通用压感仅表示收到输入，不能伪装成功。
- 普通页面入场 190ms；帖子工作区 FLIP 340ms；真实页面立即响应，不等待退场完成。悬停 / 聚焦内部链接预加载页面模块。
- 指针使用装饰环跟随，保留系统光标；仅精细鼠标显示，稳定后停止 rAF，离开 / 失焦 / 页面隐藏时停止。失焦取消未释放的压感，避免控件保持缩小。
- 手动关闭动效和系统减少动态效果统一取消额外动画；触摸不显示指针环。监听在布局提交时安装，避免首帧输入遗漏；卸载取消动画、帧与监听。

## 验证与边界

完整浏览器 40 项通过（17 / 12 / 11 三组）。最后 FLIP、预加载与样式构建后的相关专项 13 项通过；追加截图 / 长任务采样时发现首次鼠标移动发生在页面尚未就绪之前，补充页面可见前置条件，并将关键监听移到布局提交阶段，再验证 5 项相关流程。最终结果与数值见当日日志。

手机截图复查另发现区块滚动可能先于展开布局。已改为布局提交后滚动到整个目标板块，手机导航吸顶，标题为导航预留位置；相关 9 项通过，最后补充“目标标题在视口内且位于导航下方”断言后 5 项通过（33.1 秒）。修复独立提交为 `1570d45`。

详情叠层原有 overflow:hidden 会建立不滚动的容器，导致从讨论板进入时吸顶失效；改为 overflow:clip 保留滑动裁切。补充导航自身须在视口内的断言，最终相关 9 / 9（44.7 秒）通过，真实触摸取消 / 返回 / 减少动效专项 1 / 1（6.5 秒）通过；已查看修复后手机截图。

覆盖 320 / 390 / 768 / 1440px 溢出、工作区切换后的输入保留、背景路由 / 返回焦点、禁用按钮、键盘、关闭 / 系统减少动效，以及多账号业务流程。截图在有限动画完成后保存。页面代码 / CSS 全量审查和上述自动化覆盖，不能等同于每种设备、角色、数据排列的穷举。

性能使用浏览器真实 click 事件到新页面标题出现计时；自动化命令耗时另存，不能把 Playwright 等待当成用户延迟。无头 rAF 采样包含非垂直同步及操作系统调度，帧间隔偶有异常，不换算成设备 FPS，也不承诺所有设备零卡顿。真实手机软键盘、低端手机 GPU 和 200% 原生缩放仍需真机试用。
